# [v2.3.0](https://github.com/kubeflow/trainer/releases/tag/v2.3.0) (2026-08-05)

This is Kubeflow Trainer v2.3.0 release.

```bash
helm install kubeflow-trainer oci://ghcr.io/kubeflow/charts/kubeflow-trainer \
    --namespace kubeflow-system \
    --create-namespace \
    --version 2.3.0 \
    --set runtimes.defaultEnabled=true
```

## Breaking Changes

- feat(runtimes): BREAKING CHANGE: Remove Runtime Finalizers ([#3716](https://github.com/kubeflow/trainer/pull/3716) by @amirialy)
- feat(manifests): BREAKING CHANGE: Move CRD to Helm chart template directory ([#3655](https://github.com/kubeflow/trainer/pull/3655) by @andreyvelich)
  - **IMPORTANT**: if you are upgrading from Kubeflow Trainer v2.0, v2.1 or v2.2, you must first upgrade to v2.3 before upgrading to any later version.
    See [this migration guide](https://github.com/kubeflow/trainer/pull/3655#issuecomment-4864247007) for the details.
